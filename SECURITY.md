# Security Policy

This project is an open occupation blueprint — planning and traffic management support only. No cryptographic material or secrets should be committed to this repository.

The append-only audit ledger ensures transparency: all proposals, verdicts, and dispositions are recorded. The Governor ensures no binding planning authority is ever automated — escalation and human sign-off are always required for safety-critical actions.

If you discover a security issue, please report it to the project maintainers privately rather than opening a public issue.
